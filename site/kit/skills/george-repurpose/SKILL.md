# Repurpose

One idea, every channel, one approval.

## Inputs

- The source piece (article, video script, sermon transcript).
- Channel notes in BRAIN.md (which channels he uses, link habits, hashtags he likes or avoids).

## Versions to make (default set)

| Channel | Shape |
|---|---|
| Substack | Full post or a shorter letter version with a personal opening, plus a subject line and preview text |
| Facebook | 80 to 150 words, a story first, one link |
| Instagram | Caption of 50 to 120 words; carousel text for 5 to 7 slides if asked |
| YouTube community | 1 to 3 sentences plus a poll option if it fits |
| Podcast | Episode title, 3-sentence summary, show notes with links |
| Email to his list | Only if George asks; subject plus 150 words |

## Steps

1. Read the source and `voice/VOICE.md`.
2. Find the strongest line or moment. Lead each version with it, written for that channel, not pasted.
3. Keep every scripture quote exact, with its reference.
4. Add the right link per channel (site article, video, book page) from BRAIN.md.
5. Bundle all versions with the main piece, so George approves the package once.
6. george-slop-check on every version.

## Rules

- Never post. Approved packages go out through george-site-update (website) or as paste-ready text for channels that aren't connected.
- No invented stats or testimonials. No hashtag piles.
- No em dashes.

## Output

A labeled bundle: one section per channel, each ready to paste or publish.

## Try saying

"Repurpose Thursday's article for Substack, Facebook and the podcast."

## Make it yours

Edit the channel table: drop channels he doesn't use, add any he starts (for example a WhatsApp group for TOI).
